# Yopfaby App — FLUX_AI

Prototipo de interfaz para una app de generación de imágenes con IA. 
Incluye el flujo completo de usuario: bienvenida, registro, generador y perfil.

🔗 **Ver el sitio en vivo:** https://fabiola12aestrada-wq.github.io/Holasoyfabis/

## Sobre el proyecto

Este es un prototipo de diseño de producto / UI, enfocado en el flujo de 
experiencia de usuario más que en un backend funcional. La pantalla del 
generador incluye una integración real con modelos públicos de Hugging Face 
para generación de imágenes.

## Pantallas

- **Inicio** — bienvenida y opciones de acceso
- **Registro** — creación de cuenta
- **Generador** — generación de imágenes por prompt, con selección de estilo
- **Perfil** — información de usuario y configuración

## Tecnologías

- HTML, CSS, JavaScript
- Tailwind CSS
- API de Hugging Face (Stable Diffusion) para generación de imágenes
